# Credits

## DogSC

Argent is a design study of **DogSC**, the open-source macOS screen recorder and lightweight editor by laogou717 and contributors:

- https://github.com/laogou717/dogsc
- MIT License, © laogou717 and contributors

What was studied: the Soft Silver / Graphite dual appearance, the docked studio shell, the floating-island surface recipe (top-lit gradient, hairline silhouette, three-step shadow), the 10–13 px chrome / 32 px inspector type scale, the inspector and timeline rhythm, the wash-based states and the settle motion. A few token values and layout measurements were adapted from its EditorDesignTokens.swift and EditorWorkspaceLayout.swift.

No DogSC source file is copied. The HTML, CSS, JavaScript, component library, lab and all artwork in this repository are original. The original study is preserved at examples/motion as a standalone snapshot, clearly labelled as a domain example.

This project is not affiliated with or endorsed by DogSC.
